# 同一户型，两种家装方案

## 复古法式

深胡桃木人字拼、象牙白古典墙线、酒红织物、复古木框家具与八臂黄铜水晶吊灯，保留原方案。

## 意式轻奢

依据用户补充的深色意式参考图修订：以炭灰皮革和深橄榄软包为主体，搭配黑棕木作、灰褐分叉纹理大理石、暖灰墙面与古铜五金。地面及石板保留适度反射，织物、皮革与木饰面控制光泽；日间曝光和补光单独调整，避免大面积奶油白与橙色的明亮效果。

实际几何包含低矮模块沙发、体块石茶几、薄金属椅、直线软包床、平板柜门、简洁壁灯及原创黑灰抽象画。两种风格分别使用原创 Blender 灯具；意式双椭圆吊灯长947、宽631、高941mm，顶点位于2.80m假设天花，灯底约1.859m，完整投影位于固定Ø1.22m餐桌内。灯具应安装于固定家具上方，现场核对实际净高及吊点。

## 切换方式

顶部一键切换，手机竖屏与横屏均保留风格按钮。URL使用 `?style=italian` 或 `?style=french` 分享指定风格；未指定时恢复本浏览器上次选择。当前房间、环顾方向、变焦和日夜状态沿用，两套方案分别记住本次打开期间的配色。

如果切换时还在房间转场中，会先到达该房间预设视点；若新家具占用当前位置，会回到当前房间安全视点，避免进入实体家具。每套各有64件可选物件，材质介绍、家具CSV、Markdown手册与PNG文件名随当前风格更新。

首次使用另一风格时载入其独立GLB，后续往返复用已构建模型和材质；全程只保留一个渲染器、一个可见风格和当前风格碰撞体。

## 合理性检查

两套保持原墙线、门洞、安全栏杆及厨卫基本布置。意式家具在实际模型上检查：座高分别为沙发480mm、休闲椅470mm、餐椅460mm，书桌中央腿位733mm，茶几至沙发坐垫约379mm。双轨柜门全行程、书房抽屉、厨卫空腔、淋浴入口及九空间600mm人体包络连通均纳入几何回归。

该连通测试是方案级检查，不等于无障碍验收。原图净深差异、公卫移门端部仅约7mm余量、收纳不足及未定位的洗衣晾晒、空调和水电等限制继续保留在两套手册中，详见[合理性审查](设计合理性审查.md)。参考图用于风格、材质与光线方向，不替代本户型现场测绘。
