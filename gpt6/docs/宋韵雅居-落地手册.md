# MAISON · 宋韵雅居家装方案

从宋人的花、香、画、茶汲取灵感：茶褐木的细腿几案、米绢织物与青瓷器物，围合一处疏朗的当代居所。木骨绢光、原创水墨与日常厨卫相融，保留可居住的尺度。

## 材质配方

- 茶褐木 / TEA BROWN TIMBER：哑光茶褐木直拼地板、露木框坐榻与细腿几案。用现代木作实现轻巧比例；柜体保持实用收纳。
- 米绢白墙面 / SILK WHITE：参考 #E8E1D2。哑光矿物墙面配细木色门套，挂轴周围保留留白，让木构轮廓与自然光清楚呈现。
- 米绢棉麻 / UNDYED LINEN：参考 #CBBFA6。棉麻坐垫、绢面意象床头与窄收帘，纹理低反光，软垫可拆洗。
- 青瓷与黑釉 / CELADON & DARK GLAZE：灰青花器与黑釉茶盏为原创概括器形，参考宋瓷的色调与日常茶事；不作为文物复制品。
- 青灰哑光石面 / GREY MINERAL：青灰细颗粒石面用于厨房台面和湿区，采用耐水基层与适用防滑饰面；木色用于防潮柜门。
- 水墨与绢光 / INK & SOFT LIGHT：原创远山水墨挂轴、木骨绢面电灯与单枝瓶花，为日常生活留出安静的背景；灯罩需采用合格灯具材料。

## 复刻顺序

1. 现场测绘净尺寸、梁柱、窗台、门洞、墙体性质、烟道、给排水和电位。
2. 确认床/柜/沙发/餐桌尺度与门扇开启，通道建议以 800–900 mm 为优先目标并按实际空间调整。
3. 茶褐木细腿、框板门与米绢白墙统一放样；青灰石面、绢光灯和青瓷陈设共同比样。
4. 主灯与壁灯/台灯分路控制，暖光 2700–3000 K 为方案建议；厨房操作区和镜前补充功能照明。
5. 湿区柜体与淋浴按现场管线独立深化。
6. 固定木作与地面完工后，按家具清单逐件复尺进场。
