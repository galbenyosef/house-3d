日期：2026-09-05。仓库用途：比较维护者标记为 GPT6 与 Fable 的两套 3D 家装项目生成效果。

| 目录 | 原项目名 | 内容 |
| --- | --- | --- |
| `gpt6/` | `housegpt` | 场景源码、静态资产、8 个测试文件、设计文档、生成脚本、通用部署配置和吊灯元数据/预览 |

首次整理对源项目的公开相关调整：

- 新增根 README、MIT 许可证、素材说明、贡献指南、安全反馈说明、忽略规则与 Node 版本提示。
- 重写两个版本的 README，补充模型归属、准确访问前缀、运行要求、资产再生成与授权边界。
- 两个 package 增加许可证、仓库地址和 Node engines，同步锁文件根元数据；保留全部依赖版本、integrity 和原公共 npm 镜像地址。
- Fable 的 npm 资产脚本从特定 macOS 可执行文件路径改为 PATH 中的 `blender`；README 保留 macOS 替代命令。
- GPT6 部署与验证文档改为公开说明，修正过时的字体和户型图传播范围描述。

通过逐文件 SHA-256 比较，`src/`、`public/` 与几何测试全部保留原始字节；GPT6 27 个文件，Fable 136 个文件。未改动渲染、布局、家具或交互实现。

未收录 `node_modules/`、`dist/`、`.scratch/`、`.claude/`、`.DS_Store`、Python 缓存、`.orig` 备份、日志、压缩发布包和个人服务器运维记录。原项目目录中的文件保留。
